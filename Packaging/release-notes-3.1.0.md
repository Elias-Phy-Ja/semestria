Kleines Update mit Profilbild und einer angepassten IMS-Vorlage.

**Installieren:** über den [Microsoft Store](https://apps.microsoft.com/detail/9NJV8F0X7XMZ).

## Profile
- Eigenes Profilbild: im Profilmenü «Profilbild ändern» oder «Profilbild entfernen»
- Profilfeld oben links neu gestaltet: Bild links, Name und «Profil wechseln» daneben

## Noten
- IMS-Vorlage: höchstens 3 Minuspunkte statt 2, keine feste Mindestnote in Informatik mehr
- Wer die alte IMS-Vorlage unverändert benutzt, bekommt automatisch die neue
- Eigene Mindestnoten für einzelne Fächer gehen weiterhin über «+ Mindestnote in Fach»

## Updates
- Nach einem Update startet Semestria erst neu, wenn Windows die neue Version fertig installiert hat
