Verantwortlicher

EliasWyss («Entwickler»). Semestria ist ein privates Non-Profit-Projekt.

02

Grundsatz: Keine Cloud, keine Telemetrie

Semestria verarbeitet alle Daten ausschliesslich lokal auf deinem Gerät.

Keine Telemetrie Keine Nutzungsstatistiken Kein Tracking Keine Werbung Kein Backend-Server

03

Welche Daten werden verarbeitet?

Datenkategorie Speicherort Übertragung
Feed-URL (Schulnetz-Kalender) %LOCALAPPDATA%\Semestria\config.json
DPAPI-verschlüsselt		 Nur zum Schulnetz-Server (direkter Abruf)
Microsoft-Zugangstoken %LOCALAPPDATA%\Semestria\token_cache.bin
DPAPI-verschlüsselt		 Nur zu Microsoft Graph API
Konfigurationsdaten %LOCALAPPDATA%\Semestria\config.json Keine Übertragung
Kalendereinträge Arbeitsspeicher (nicht persistiert) Microsoft Graph API → dein Outlook-Kalender
DPAPI — Die Feed-URL und das Microsoft-Token werden mit dem Windows Data Protection API verschlüsselt, das an dein Windows-Benutzerkonto gebunden ist. Nur du (auf diesem Gerät) kannst diese Daten entschlüsseln.

04

05

Deine Rechte

Du kannst jederzeit:

06

Datensicherheit

Feed-URL und Microsoft-Token sind mit DPAPI verschlüsselt. Es findet keine Übertragung an Dritte ausser Microsoft (Kalender-Sync) und deinem Schulnetz-Anbieter (Feed-Abruf) statt.

07

Minderjährige

Die App richtet sich an Schülerinnen und Schüler. Es werden keine besonderen Kategorien personenbezogener Daten verarbeitet.

Geltungsbereich

Diese Nutzungsbedingungen gelten für die Verwendung der App «Semestria». Mit der Verwendung erklärst du dich mit diesen Bedingungen einverstanden.

02

Leistungsbeschreibung

Semestria ist eine kostenlose, quelloffene Desktop-App für Windows. Sie liest deinen persönlichen Schulnetz-Kalender und schreibt Prüfungen sowie Schultermine in deinen Microsoft Outlook-Kalender. Die App funktioniert rein lokal auf deinem Gerät — es werden keine Daten an eigene Server übertragen.

03

Kostenlose Nutzung

Die App wird kostenlos zur Verfügung gestellt. Es besteht kein Anspruch auf Support, Updates oder Weiterentwicklung.

Die Feed-URL enthält ein persönliches Token. Du bist selbst verantwortlich für die sichere Aufbewahrung. Teile deine Feed-URL mit niemandem.
