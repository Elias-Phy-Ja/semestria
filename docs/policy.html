02

Grundsatz: Deine Daten bleiben bei dir

Semestria verarbeitet deine Daten ausschliesslich lokal auf deinem Gerät.

Keine Telemetrie Keine Nutzungsstatistiken Kein Tracking Keine Werbung Kein Konto, kein Server mit deinen Daten

03

Welche Daten werden verarbeitet?

Datenkategorie Speicherort Übertragung
Feed-URL (Schulnetz-Kalender) %LOCALAPPDATA%\Semestria\profiles\<Profil>\config.json
DPAPI-verschlüsselt		 Nur zum Schulnetz-Server (direkter Abruf)
Microsoft-Zugangstoken %LOCALAPPDATA%\Semestria\profiles\<Profil>\token_cache.bin
DPAPI-verschlüsselt		 Nur zu Microsoft Graph API

DPAPI: Die Feed-URL und das Microsoft-Token werden mit dem Windows Data Protection API verschlüsselt, das an dein Windows-Benutzerkonto gebunden ist. Nur du (auf diesem Gerät) kannst diese Daten entschlüsseln.

04

Nachrichten vom Entwickler

Etwa zehn Sekunden nach dem Start lädt die App die öffentliche Datei https://semestria.elias-wyss.ch/news.json. Dabei sendet die App keine Angaben über dich, keine Kennung und keine Daten aus der App.

Wie bei jedem Webseitenaufruf erhält der Server deine IP-Adresse und technische Angaben zur Anfrage (Zeitpunkt, angefragte Datei). Die Seite liegt beim Webhoster Hostinger, der solche Zugriffe gemäss seiner Datenschutzerklärung kurzzeitig protokollieren kann. Der Entwickler wertet diese Protokolle nicht aus. Welche Nachrichten du schon gesehen hast, speichert die App nur lokal.

Den Abruf kannst du in den Einstellungen der App ausschalten.

09

Datensicherheit

Feed-URL und Microsoft-Token sind mit DPAPI verschlüsselt. Verbindungen zu Schulnetz, Microsoft und dem Nachrichtenserver laufen nur über HTTPS. Es findet keine Übertragung deiner Daten an Dritte ausser Microsoft (Kalender-Sync) und deinem Schulnetz-Anbieter (Feed-Abruf) statt.

02

Leistungsbeschreibung

Semestria ist eine kostenlose, quelloffene Desktop-App für Windows. Sie liest deinen persönlichen Schulnetz-Kalender, zeigt ihn in der App an und schreibt auf Wunsch Prüfungen sowie Schultermine in deinen Microsoft Outlook-Kalender. Dazu kommen Aufgaben, Notizen und Noten, die du selbst einträgst. Deine Daten bleiben auf deinem Gerät.

03

Kostenlose Nutzung

Die App wird kostenlos zur Verfügung gestellt. Es besteht kein Anspruch auf Support, Updates oder Weiterentwicklung.
